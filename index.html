§ 03

专题线索 · 四条进入方式

READING PATHS
PATH A · 地缘

从一座城开始，而不是从一部爆款开始

用拍摄地串起片目：重庆的潮湿、首尔的公寓密度、东京的沿线车站、柏林的墙体痕迹。同一座城看三到五部，风格差异会比榜单更直观。

  1. 先定城市，再定年代区间
  2. 每城只看两部，别一口气刷完
  3. 把观看感受写回自己的片单
PATH B · 作者

导演的三部曲，是最小的入门单元

单看一部容易被题材误导。这里给出的顺序是“最早成型作 → 中间转折作 → 最近一部”，让你看清手法是怎么长出来的。

  1. 别按豆瓣热度挑起点
  2. 留意摄影师与美术的重复合作
  3. 转折作往往比代表作更值得聊
PATH C · 介质

修复版、院线版、剪辑版，别混着记

版本是观影体验的一部分。索引里把画幅、时长、配音与修复年份拆开写，方便你决定值不值得为某个版本再坐两个小时。

  1. 先查画幅再查片长
  2. 4K 修复不等于重新调色
  3. 剪辑版差异会改写人物动机
PATH D · 门槛

按时间预算挑，而不是按评分挑

设了三条线：四十分钟短片、两小时单机、六集以内。通勤、周末、病假三天，各有对应的进入方式，省掉“今晚看什么”的焦虑。

  1. 40 分钟：一个情绪的完整闭环
  2. 120 分钟：需要一次不被打断的座位
  3. 6 集以内：适合出差途中的连续叙事
